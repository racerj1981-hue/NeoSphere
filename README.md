# 🚀 NeoSphere

A modern, fast, unblocked web games platform built with React, Vite, and Tailwind CSS.

---

## ✨ Features

- 🎮 **Game Library**: Wide selection of games with quick search and category filtering.
- 🔄 **Real-Time Cross-Tab Sync & Play Counter**: Plays persist locally and update live across open tabs.
- 🔒 **Tab Cloaking & Panic Button**: Disguise tab titles/icons or trigger immediate panic redirects for privacy.
- 🌙 **Modern Dark UI**: High-contrast, responsive dark aesthetic.
- ⚡ **Built for Speed**: Powered by Vite and optimized client-side architecture.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Deployment**: GitHub Pages (Automated via GitHub Actions)

---

## 🚀 GitHub Pages Deployment Setup

To host NeoSphere on GitHub Pages:

1. Go to your repository **Settings** on GitHub.
2. Select **Pages** from the sidebar menu.
3. Under **Build and deployment**, set **Source** to **`GitHub Actions`**.
4. The `.github/workflows/deploy.yml` action will automatically build Node.js 22 and deploy your app to GitHub Pages on every push.

## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/racerj1981-hue/NeoSphere.git

# 2. Navigate to directory
cd NeoSphere

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```
